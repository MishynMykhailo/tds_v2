# TDS v2 — чистая перепись

Полная переписи TDS (Traffic Distribution System) с нуля — старый бэкенд был
декомпилирован из ionCube и восстановлен автоматическим инструментом (~40+
системных багов декомпиляции найдено и исправлено в старом проекте перед
переписью). Здесь — новый, чистый, читаемый проект, без переноса кода из
старого репозитория.

Старый проект (продолжает работать в проде, не трогаем) —
`/Users/mykhailomishyn/Downloads/tds_source-main — without KT`.

## Структура

- `backend/` — Laravel + Laravel Octane (RoadRunner) — админка, CRUD-модули
  (Campaigns, Offers, Streams, Users, Reports и т.д.)
- `traffic-core/` — лёгкое PSR-7-ядро без Eloquent/Facades — обработка клика
  (бот-детект, матчинг стримов, рендер лендингов). Самый нагруженный по RPS
  путь, физически изолирован процессом RoadRunner/Goridge — задел на будущий
  переезд в Go.
- `frontend/` — React + Vite, админ-панель поверх того же API-контракта.
- `deploy/` — docker-compose (только MySQL+Redis), nginx-шаблон, systemd-юниты,
  bash-установщик.
- `docs/ARCHITECTURE_PLAN.md` — полный план архитектуры и обоснование решений
  (Laravel vs лёгкий стек, ionCube-защита, установка на VPS) — читать первым.
- `docs/legacy-reference/` — ПОВЕДЕНЧЕСКАЯ СПЕЦИФИКАЦИЯ из старого проекта.
  Тестов в старом проекте нет — эти документы единственный источник правды о
  том, как система ДОЛЖНА себя вести:
  - `FIXES_LOG.md` — все найденные и исправленные баги старого кода, файл за
    файлом.
  - `BUG_PATTERNS.md` — каталог из 14 паттернов декомпиляционных багов.
  - `RISKY_FIXES.md` — места, где поведение было ИЗМЕНЕНО, а не восстановлено
    — сознательные решения, стоит перепроверять при переносе.
  - `TODO_IMPROVEMENTS.md` — заглушки вместо вырезанных вендорских сервисов.
  - `frontend/backend_api_reference.md` — точный текущий API-контракт
    (`?object=...`), который новый бэкенд обязан повторить 1-в-1.
  - `frontend/round*_findings.md` — постраничные QA-находки по каждому модулю.
  - `frontend/design_reference.md` + `frontend/design/screenshots/` — дизайн
    старой админки (цвета/типографика/компоненты) для визуального 1-в-1 при
    переписывании фронта.

## Ключевое правило переноса

Внешний API-контракт (`?object=Controller.action`, формат JSON-ответов)
**не меняется** — это сознательный слой совместимости, не автоматическое
свойство Laravel. Каждый переносимый эндпоинт сверяется с
`docs/legacy-reference/frontend/backend_api_reference.md` и соответствующим
разделом `FIXES_LOG.md`, а не пишется "как удобнее".
